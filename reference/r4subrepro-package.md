# r4subrepro: Reproducibility and Reviewability Indicators for Clinical Submissions

Scores the computational reproducibility and reviewer readiness of an R
based regulatory submission by statically inspecting its analysis code
folder. Checks for a captured package environment, path hygiene, a
single entry point, hidden setup assumptions, undeclared proprietary
packages, clean run evidence, and script complexity, following the
reproducibility guidance for making R submissions reviewable for
regulators. Emits standardised R4SUB (Ready for Submission) evidence
table rows via 'r4subcore' for integration with 'r4subscore' and
'r4subprofile'.
