# Print a Reproducibility Result Summary

Print a Reproducibility Result Summary

## Usage

``` r
# S3 method for class 'repro_result'
print(x, ...)
```

## Arguments

- x:

  A `repro_result` object from
  [`reproducibility_summary()`](https://r4sub.github.io/r4subrepro/reference/reproducibility_summary.md).

- ...:

  Ignored.

## Value

Invisibly returns `x`. Called for the side effect of printing the
per-indicator results and the weighted overall score.
