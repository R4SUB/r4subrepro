# Print a Computational Environment Comparison

Print a Computational Environment Comparison

## Usage

``` r
# S3 method for class 'repro_environment_diff'
print(x, ...)
```

## Arguments

- x:

  A `repro_environment_diff` object from
  [`compare_environments()`](https://r4sub.github.io/r4subrepro/reference/compare_environments.md).

- ...:

  Ignored.

## Value

Invisibly returns `x`. Called for the side effect of printing the
environment differences.
