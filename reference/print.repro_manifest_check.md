# Print a File-Hash Manifest Verification

Print a File-Hash Manifest Verification

## Usage

``` r
# S3 method for class 'repro_manifest_check'
print(x, ...)
```

## Arguments

- x:

  A `repro_manifest_check` object from
  [`repro_manifest_verify()`](https://r4sub.github.io/r4subrepro/reference/repro_manifest_verify.md).

- ...:

  Ignored.

## Value

Invisibly returns `x`. Called for the side effect of printing the file
counts and any differences from the manifest.
